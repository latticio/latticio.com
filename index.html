How it works

You ask a question. Your AI assistant picks the right tools, queries your devices, and explains what it found.

You: "Are any BGP neighbors down on spine-01?"
  |
AI Assistant (Claude Desktop, Cursor, VS Code)
  |  selects: net_get_bgp_summary(host="spine-01")
  v
latticio → validates input, checks rate limits, selects driver
  |           → queries device via eAPI / RESTCONF / NETCONF / REST
  |           → sanitizes credentials, logs audit trail
  v
AI: "All 4 BGP neighbors on spine-01 are Established.
     leaf-01 and leaf-02 (AS 65001): 24 prefixes each.
     leaf-03 and leaf-04 (AS 65002): 20 prefixes each."

Built for production networks

Multiple safety layers active by default. Enterprise auth and RBAC for team deployments.

Read-only by default

All write operations blocked unless explicitly enabled. Dangerous commands like reload, write erase, and bash are permanently denied.

Vendor-agnostic tools

88 net_* tools return the same structured output regardless of vendor. Set the platform field in your inventory and every tool auto-selects the right driver.

Input validation

Every parameter is validated against CLI injection patterns before reaching any device. Semicolons, pipes, backticks, subshell syntax, null bytes — all blocked.

Config sessions

Stage changes in atomic config sessions. Review diffs before committing. Set rollback timers that automatically revert if something goes wrong.

Auth & RBAC

OAuth 2.1 / JWT authentication with scope-based access control. Four scopes: network:read, network:write, network:admin, network:audit.

Audit & observability

Structured JSON audit log of every tool call with user and tenant attribution. Prometheus metrics export. Per-device circuit breakers and rate limiting.

Credential sanitization

Passwords, secrets, community strings, and API keys are automatically redacted from every response before reaching the AI assistant.

Progressive discovery

Only meta-tools load at startup. Tool categories are loaded on demand as the AI needs them, keeping the context window efficient.

Plugin system

Extend with custom drivers, compliance packs, and tool modules via Python entry points. No core code changes needed.
